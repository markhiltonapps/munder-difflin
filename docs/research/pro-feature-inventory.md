## Recommended build order

1. **Sidebar polish (S items 1g, 1i, 1j, 1k)** — the rail already exists; adding Keep-my-agent-order, hover ticket details, engine/model/ticket on rows and a right-click menu closes the visible gap to the Pro sidebar in days, and 1k is also a free-build 0.5.3 promise.
2. **Free-build parity that is cheap and widely advertised**: Opus 5.5 default, compaction 40 min/30 %, ticket keys + per-agent Tasks tab + date filters, Ask me on every agent, Telegram/Linear webhook presets. These are what a 0.5.3 user expects and none needs new native code.
3. **Local transcription engine (2g, 2h)** — the single biggest "Pro" claim ("cancel Granola and Wispr Flow") and a prerequisite for everything in the Stapler. Swap `freeflow.ts` from Groq-only to an engine abstraction (bundled whisper.cpp + model download, Apple Speech on macOS 26, Groq as fallback) and add the vocabulary. Keep the existing composer mic as the first consumer.
4. **Stapler window, Record message, Make invisible, screenshots (2a, 2c, 2i, 2b, 2j)** — a frameless always-on-top window reusing the recorder and the composer's attachment path; content protection is one Electron call.
5. **Dictate into any app (2f)** — needs OS-level key hooks and Accessibility typing; do after the engine exists.
6. **Meetings with You/Them (2d, 2e)** — system-audio loopback per OS is the hardest native piece; last of the Stapler.
7. **Workspace screens (1l–1r)** — Tasks views/proposals, unified Inbox, Memory three-shape results, Capabilities role bundles + Who-has-what, Temps ledger. Mostly re-composition of existing Command Center tabs; schedule after the Stapler because the data layer already exists and the free sidebar already links to the tabs.
8. **Skip**: licence/checkout (7), Founders' Wall (6: strip the hero-card offer), Private Cloud/Sandboxes (4), Private Network/Teams relay (5) and the mobile app (3) — hosted or unreleased upstream; revisit the mobile idea as a thin client over the existing REST API once the floor is stable.
